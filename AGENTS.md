# Repository Rules for AI Agents

- Read `CLAUDE.md` before making any changes and follow its project guidance.
- Do not touch WHOOP BLE or protocol code, `WhoopStore`, or HealthKit code unless explicitly asked.
- Never hand-edit `Strand.xcodeproj`; `project.yml` is the XcodeGen source of truth.
- Preserve the existing architecture and established project patterns.
- Keep changes small, targeted, and limited to the requested concern.
- Do not refactor unrelated code.
- Run relevant tests and build checks before finishing.
- Never reset, discard, or overwrite user changes.
